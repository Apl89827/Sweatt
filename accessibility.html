Accessibility Statement

Last updated: January 1, 2026

Our Commitment

Sweatt Shop is committed to making this website usable by people of all abilities, including those using screen readers, keyboard-only navigation, or other assistive technology.

Conformance Target

We aim to meet WCAG 2.1 Level AA, the widely accepted standard for web accessibility, across every page of this site.

Measures We Have Taken

  • Semantic HTML landmarks (header, nav, main, footer) for screen-reader navigation.
  • A "skip to content" link for keyboard users to bypass repeated navigation.
  • Visible focus indicators on every interactive element, not just default browser styling.
  • Native <dialog> elements for modals, which provide a built-in keyboard focus trap and Escape-to-close.
  • Native <details> accordions for FAQ content, fully operable by keyboard and screen readers with no custom JavaScript required.
  • Text and background color combinations checked against a minimum 4.5:1 contrast ratio (3:1 for large text).
  • Form fields with associated labels, and error messaging tied to its field.
  • Motion and animation that respects prefers-reduced-motion, disabling non-essential transitions for users who request it.
  • Alt text on informational images; decorative images are marked so screen readers skip them.

Known Limitations

We are not aware of any outstanding accessibility barriers on this site. If you encounter one, please let us know using the contact details below and we will address it.

Feedback

If you experience any difficulty accessing content on this site, contact us through our contact form. We aim to respond to accessibility feedback within a few business days.
